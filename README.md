# 武汉大型购物中心二维码营销效果因素分析

> 本仓库根据本人本科阶段参与的《基于武汉本地二维码在大型购物中心营销效果因素分析报告》整理，展示消费者研究、问卷设计思路和定量分析方法。

## 研究背景

项目关注大型购物中心场景下二维码营销的效果及其影响因素，围绕消费者特征、激励方式、内容体验、使用便利性和消费场景开展分析，研究哪些因素可能影响消费者的扫码意愿、互动体验与营销效果。

## 本人在原项目中的工作

- 参与消费者调研和问卷设计；
- 参与问卷样本整理、变量梳理与影响因素分析；
- 从用户特征、激励方式、内容呈现、使用便利性及场景适配等维度梳理研究问题；
- 参与形成营销效果分析材料，为不同消费场景的方案优化提供依据。

## 复现演示

推荐 Python 3.10+：

```bash
pip install -r requirements.txt
python src/generate_demo_data.py
python src/analysis_demo.py
```

脚本展示字段完整性检查、变量范围检查、缺失值处理、描述性统计、相关性分析和简单的 OLS 回归，运行后结果保存到 `outputs/`。

## 数据与成果真实性说明

**该项目经历是真实的；本仓库没有公开原始问卷，也不提供原项目真实统计结果。** `generate_demo_data.py` 随机生成的 300 行数据全部是模拟样本，样本数、模拟变量间关系和回归结果均不能作为原项目的真实发现。当前演示代码是根据项目研究思路重新编写，用于展示数据处理和研究方法，不应理解为原项目的原始代码或研究成果。

如需用于正式研究，应在合规取得真实原始数据后重新核验研究设计、变量定义和统计模型。
